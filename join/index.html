Don't have Ashen Path yet?

  1. Have the Mortuus demo in your Steam library, with Steam signed in.
  2. Install the newest Ashen Path (the top release). You need the same version as your friend.
  3. Come back to this link and press Join the lobby in Steam.
The Ashen Path is an unofficial, fan-made mod and isn't affiliated with the makers of Mortuus. This page only builds a steam://joinlobby link from the address; it stores and sends nothing.
